Manual two-tab conflict test

What this proves: two tabs editing the same chat. The second save must be refused as a conflict, not silently overwrite the first.
  1. Click Open second tab (allow popups if asked). Both tabs show this panel.
  2. In each tab click Load. Both read the same rev.
  3. Type a different title in tab A and click Save. It succeeds, rev advances.
  4. Without reloading, type a different title in tab B and click Save.
  5. Tab B must be refused, showing its expectedRev against the store's currentRev. That is the pass condition.
